# Wochen-Vokabeln

Jede Datei in diesem Ordner wird vom Vokabeltrainer beim Öffnen automatisch als neue Woche übernommen.

- Erlaubte Formate: `.xlsx`, `.xls`, `.csv` (mit Semikolon getrennt), `.txt`
- Der Dateiname ist der Name der Woche, z. B. `Woche 45.xlsx`
- Spalte A = Englisch, Spalte B = Deutsch (eine Kopfzeile „Englisch / Deutsch“ ist erlaubt)
- Bereits geladene Wochen werden nicht erneut geladen. Wurde eine Datei geändert, den Dateinamen ändern (z. B. `Woche 45 v2.xlsx`).
